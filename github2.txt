2. SITO WEB — RIEPILOGO
--------------------------------------------------------------------------------
File creati nella cartella sitoweb-comunita/:

  index.html       -> Home (hero, statistiche, servizi in evidenza, missione,
                      attività in evidenza, CTA)
  chi-siamo.html   -> Chi siamo (missione, timeline, valori, team)
  servizi.html     -> Servizi (5 ambiti con ancore #abitazioni #centri-diurni
                      #accompagnamento #laboratori #famiglie; "per chi";
                      "come funziona" in 3 passi; CTA)
  attivita.html    -> Attività (laboratori, calendario settimanale, FAQ, CTA)
  contatti.html    -> Contatti (sedi, telefoni, orari, mappa segnaposto, form
                      con invio simulato)
  css/style.css    -> Stili condivisi (token di design in :root, tema
                      verde-salvia + ambra)
  js/main.js       -> Menu mobile, intestazione sticky, form, anno nel footer
  README.md        -> Istruzioni di personalizzazione
  contesto.txt     -> Riepilogo della parte di sviluppo del sito

Caratteristiche generali:
  - Linguaggio: italiano.
  - Tecnologia: HTML + CSS + JavaScript vanilla (nessun framework/build).
  - Accessibilità: skip-link, landmark semantici, focus visibile, menu da
    tastiera, supporto a prefers-reduced-motion, contrasto curato.
  - Responsive: layout fluido, menu "hamburger" sotto gli 860px.
  - Icone/logo in SVG inline; funziona anche offline (nessun link rotto).
  - Contenuti (nome, contatti, numeri, storia, team) = placeholder da
    sostituire con i dati reali.

4. COMANDI UTILI (da eseguire in TERMINALE, dove "gh" è loggato)
--------------------------------------------------------------------------------
# --- Pubblicare il sito / il primo push ---
cd /home/massimo/progetto03/sitoweb-comunita
gh auth status

# Firma il commit con la propria identità GitHub
LOGIN=$(gh api user --jq '.login')
GHID=$(gh api user --jq '.id')
git config user.name "$LOGIN"
git config user.email "$GHID+$LOGIN@users.noreply.github.com"
git commit --amend --reset-author --no-edit

# Crea il repo privato e pubblica (imposta origin + push su main)
gh repo create sitoweb-comunita --private --source . --remote origin --push

# Verifica
git remote -v
git log --oneline


# --- In seguito: sincronizzare modifiche con GitHub ---
cd /home/massimo/progetto03/sitoweb-comunita
git status                 # cosa è cambiato
git add -A                 # tutti i cambiamenti (o: git add <file>)
git commit -m "messaggio che spiega la modifica"
git push                   # invia su GitHub

# Verifica allineamento
git status                 # "up to date with 'origin/main'" = ok
git log --oneline          # ultimo commit


# --- Se il push fallisce per SSH ---
ssh-add ~/.ssh/id_ed25519
ssh -T git@github.com      # deve rispondere: "Hi cuggio-prog!"
